# ECO MISSION — Save Our Planet

A standalone Vietnamese classroom quiz game. No build step, framework, or API key is required.

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox, Safari).
3. Click **BẮT ĐẦU NHIỆM VỤ**.

## Included

- 10 questions: 4 multiple-choice, 3 true/false, 3 short-answer.
- 30-second timer per question, 3 lives, scoring and immediate explanations.
- Final score, answer review, copyable result, responsive layout.
- All styles and game logic are included in `index.html`.

## Publish as a public website

This is a static website. Upload the `index.html` file (or the extracted project folder) to any static hosting service such as Netlify Drop, GitHub Pages, or Cloudflare Pages. No server is required. For Netlify Drop, sign in to Netlify, open its Drop deploy page, and drag the extracted folder into the upload area. The hosting service will provide the public URL after deployment.

## Content note

The Canva presentation was not accessible when the research brief was prepared. The current quiz therefore uses the illustrative environmental-protection topic from that brief. Replace the question data in the `questions` array in `index.html` with facts from the actual presentation before presenting it as slide-aligned content.
